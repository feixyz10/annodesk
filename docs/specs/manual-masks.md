# 手工 mask 创建与修补

设计日期：2026-11-01。状态：**0.5.0已实现**。画笔、橡皮擦、多边形增减和人工编辑保护已实现。

与[主规范](annodesk.md)、[辅助框](assisted-boxes.md)、[候选掩码](mask-candidates.md)共同阅读。验收目标与实际验证范围在末节区分。

## 1. 目标、方案与边界

让用户无需模型即可从零标注实例mask，也能精确修补SAM/导入的结果，保留孔洞、细小结构和不连通部分。采用已有Vue/Pinia/Konva/Canvas交互与原图像素坐标，不新增编辑器框架。

已讨论方案：

| 方案 | 优点 | 代价 | 决定 |
| --- | --- | --- | --- |
| 仅多边形 | 大块直边区域快 | 复杂边界、孔洞修补不方便 | 不选 |
| 仅画笔/橡皮擦 | 像素修补直接 | 大面积轮廓描绘效率低 | 不选 |
| 画笔＋橡皮擦＋多边形增减，共用像素mask | 从零创建与精修都覆盖，只有一份真值 | 需统一手势/撤销/推理保护 | 用户已选择 |

多边形是一次绘制操作，闭合后合入mask，不维护另一套长期可拖顶点的矢量对象。首版不做软笔刷、压感、智能吸附、魔术棒、填充桶、实例合并/拆分、任意轮廓顶点编辑或自动边缘优化。无需SAM权重、Torch初始化或GPU。

## 2. 空间布局：固定工具栏，不增加画布上方行数

沿用当前浅色界面、左右可调栏宽、固定宽度左侧竖向工具栏和顶部48px画布工具条。右侧仍为Objects＋Image properties，不插入常驻手工编辑面板，不自动展开实例详情，不挤压缩略图条。

### 左侧工具栏

现有选择区、检测框、SAM提示、History保持独立。新增 **Mask / 掩膜** 组，三个直接可见图标：Brush、Eraser、Polygon；不要把它们藏进长按菜单或更多菜单。工具栏宽度保持现状，低高度窗口仅工具栏自身纵向滚动，不导致页面滚动或压缩画布。组名用短词，完整用途通过快速tooltip与aria-label提供。

### 顶部工具条

手工工具激活时，仅将左侧原“模型＋当前图分割＋Auto-segment”区域替换为当前手工工具参数；右侧Layers、Pan、缩放、Fit、属性开关原位保留。退出手工工具恢复模型区域。需要设置模型时，按V切回选择工具即可访问原模型入口。替换区域不变高、不换行，不改变自动分割设置值。

| 工具状态 | 顶部左侧内容示意 | 说明 |
| --- | --- | --- |
| Brush | `Brush · Object 4   Size [24] px  [slider]` | 圆形硬笔刷，添加像素 |
| 画笔 | `画笔 · 实例4   大小 [24] px  [滑条]` | 与英文同一控件顺序 |
| Eraser | `Eraser · Object 4   Size [24] px  [slider]` | 减去当前实例像素 |
| Polygon | `Polygon · Object 4   [Add / Subtract] [Finish] [Cancel]` | 只在绘制中开放完成/取消 |
| 多边形 | `多边形 · 实例4   [添加 / 减去] [完成] [取消]` | 两个模式互斥且有文字标签 |
| 新建 | `Brush · New object` / `画笔 · 新物体` | 不先创建空实例 |

对象身份仅显示稳定的实例序号；类别与改类入口仍在既有palette/实例行，避免长类别名称撑满工具条。对象ID或类别不因切换工具改变。没有有效目标时，橡皮擦和多边形减去给出简短提示，画布不执行操作。

空间不足时依次隐藏滑条（保留数值输入和快捷键）、缩短工具上下文标签；仍不足则仅左侧参数区横向滚动。右侧视图控件不被推走，不出现第二行。现有窄窗口右栏开关行为保留；数值/模式/完成操作均可键盘访问。

底部既有状态栏显示一句情境提示，不新增提示行；长说明放tooltip/快捷键窗口。错误沿用固定浮层，不能把页面顶开。不在图像上方悬浮永久参数面板，避免遮挡细节。

## 3. 目标、笔刷与多边形

### 3.1 新建或编辑

- 名称单击或画布明确选择实例后，画笔/多边形添加编辑该实例mask；只有框或提示的实例也可添加mask，保留UUID/类别/框/提示。
- 切到手工工具不自动命中鼠标下的其他实例；操作始终绑定顶部所示对象。悬停预选在绘制工具下暂停，避免画到一半目标改变。
- 按N清除当前目标并进入“新物体”，保留当前手工工具；若为橡皮擦或多边形减去，则切为画笔或多边形添加。首次有效操作创建实例，继承默认类别；未分配类别允许草稿，导出仍遵循现有校验。
- 不自动创建检测框，不同步移动或扩大已有检测框。需要时显式使用mask转框。
- 不删除或裁切其他实例；不同实例可重叠，一个实例可含多个分离区域和孔洞。
- 锁定实例禁止修改；隐藏mask禁止不可见编辑，显示“显示掩膜以编辑”恢复入口，不擅自改变Layers或实例开关。新增实例需要项目mask图层可见。
- 从Detection任务主动选择手工mask工具时切到Segmentation任务，统计/审核按钮同步；任务切换不改变图层显隐设置，隐藏仍按上条处理。

### 3.2 画笔/橡皮擦

圆形硬边笔刷，大小表示**原图像素直径**，默认24px，范围1–512px，整数输入与滑条联动。画笔与橡皮擦各自记忆大小（浏览器偏好），跨缩放保持实际像素大小。首版无软边或透明度绘制：结果始终二值mask。

光标用黑白双描边圆环显示实际作用范围，中心小十字；指针附近的小加号/减号区分画笔与橡皮擦。圆环按画布缩放显示，最小中心标记保持可辨认，不把视觉标记尺寸误当涂抹范围。

点击是一枚圆点；拖动按连续轨迹补齐采样间隙，快速移动不得形成串珠断点。所有运算裁到图像边界，以像素中心落入扫掠圆形区域为填充规则；不把抗锯齿透明边当作真值。未命中任何变化的橡皮擦/重复绘制不新增撤销记录，不使审核失效。

### 3.3 多边形

逐点点击绘制边界，当前边随鼠标预览；Enter或点击起点闭合，至少三个不同顶点且覆盖有效像素。完成按钮提供等价入口；Backspace移除上一个顶点，Esc取消整条未完成路径。首版不靠双击完成，避免与现有双击改类/事件重入混淆。

添加为mask与闭合区域的并集；减去为差集。按像素中心及even-odd填充规则栅格化，自交也有确定结果；路径仍显示交叉区域预览。模式在有顶点时禁止切换，完成或取消后可换。闭合后不保留可编辑顶点，修改用后续画笔/橡皮擦/多边形操作。

## 4. 完成、取消、保存、擦空

- 每次pointerdown到pointerup是一笔；一次闭合多边形是一步。绘制中为瞬时草稿；结束时一次性更新mask并进入既有撤销/自动保存流程，不对每个pointermove写后端。
- 完成一笔即可继续画，不弹确认窗。Undo恢复整笔/整片，Redo重做；同一历史栈同时支持框、提示及mask操作，不能各自撤销出相互矛盾的数据。
- 图片、项目、实例、工具、任务变化，隐藏/锁定目标、窗口失焦或pointercancel均取消未完成手势，不提交半笔。已完成笔画保留并正常保存。出画布但仍按住指针由pointer capture接收，超出图像部分裁剪。
- 绘制中Space不把同一拖动切成平移；抬起指针后可开始平移。多边形顶点之间可按Space平移，保留未闭合路径；释放后继续点击。缩放沿用原工具，所有顶点和笔刷都用原图坐标。
- 擦掉最后一个像素时清除该实例mask与其polygons，保留框/提示；完全无几何则移除空实例。可一步撤销。不创建空RLE，不自动确认无目标，不自动批准。保留框/提示的实例继续保留手工保护标记，防止刚擦掉又被自动补回。
- 有实际mask变化时只影响Segmentation：ok回pending，uncertain保持，清除Segmentation的explicit_empty；Detection与现有框不变，共享改类仍按原规则影响两任务。本功能在Excluded图片上禁用手工mask编辑，先取消排除后才可绘制；不扩展修改现有检测框工具行为。
- 自动保存失败保留本地已完成编辑及重试提示，不显示“已保存”；切图遵守现有保存失败阻止导航规则。

## 5. 与SAM交互：人工修改不得被无意覆盖

这是首版必要行为，而非后续优化。

- 开始有效手工手势前，取消当前候选预览并使该客户端在途SAM结果失效；不等待响应来决定目标。手势完成前即冻结编辑代次，取消手势也不复活旧响应。
- 任何手工mask修改后持久化`mask_manually_edited: true`（Instance新增字段，缺省false），而不只依赖`source`；现有source同时承载导入/模型来源，不能作为可靠的手工保护开关。
- 新建手工mask也设置标记。标记不等于Approved，不改变显隐，也不禁止用户显式调用SAM；自动补全则按下条跳过。普通保存、重新打开、复制项目保留；Undo/Redo随几何一起恢复。
- 自动切图分割、Segment current及批量/CLI补mask跳过该标记实例，即使其mask已被人工擦空；在范围统计中列出“手工编辑保护 / Manual edits protected”。现有其他类别/歧义/锁定/审核保护继续适用。
- 用户明确对受保护实例使用SAM正负点/框细化或Refine mask时，仍可推理，但返回只读预览；必须Apply replacement / 应用替换后才替换。取消保留精修结果与刚编辑的提示。新提示更新该预览，不能走自动直接保存通道。
- 受保护实例单掩码预览只有一个结果；Generate candidates仍可显式请求多个。共用现有候选会话、单在途请求限制和失效校验，不开两条推理队列。
- 单结果保护预览也不能新增画布外的候选条挤占空间：顶部左侧参数区临时变为“预览替换 · 应用替换 · 取消”；多候选选择使用同一区域的1/2/3按钮，详细质量信息放tooltip。本功能只调整受保护mask的预览呈现，现有未受保护候选流程暂沿用原布局。预览目标mask不可见时需先显示，不能看不到就Apply。
- 确认替换后仍保留手工保护标记；再次细化仍需确认。用户可继续创建新实例，不需要清除保护。首版不另加“解除保护”开关。
- SAM通常按提示重新预测，不承诺把当前手绘像素作为模型输入或保留手工区域；提示文案必须说明“替换当前掩膜”，不得称为无损追加。

## 6. 数据、并发与实施边界

原图坐标、RGB预览与EXIF/TIFF处理沿用主规范。已有RLE是编辑基底，不能从彩色overlay或简化polygon反推有损mask；仅有polygon的导入实例第一次编辑前按同一像素规则栅格化。RLE与派生polygons分离，后端保存重新生成投影。

前端只持有当前编辑实例的二值工作缓冲及本次笔画草稿，不为全项目缓存整图像素。局部预览用Canvas，描边/框/提示继续共用既有坐标变换。完成操作在本地编码RLE、更新标注并调用现有保存流程；不新增模型推理API，不在每个鼠标事件往返服务器。前端实现COCO压缩RLE codec，与pycocotools相互解码验证并保护孔洞/断连/像素边界。显示缓存用本地编辑代次区分，不仅依赖服务器revision，未保存结果也须立即可见。

手势冻结项目会话、图片ID/尺寸、实例ID、原始mask状态与本地编辑代次。后台刷新、推理应用或外部编辑改变基底时取消草稿，不能把旧笔画合到新几何。保存仍验证revision、图片指纹和外部投影冲突，采用原日志事务。后台批次依照已冻结快照计算，提交时发现人工保存的revision变化必须拒绝；未保存并发冲突保留前端编辑，不静默以服务端返回覆盖。

沿用现有最多60步撤销基础；对大图进行实际内存/交互测试，避免每个移动事件保存完整RLE。是否需要局部差分或Web Worker在实现时根据性能证据决定，不预先引入通用图像编辑历史框架。

YOLO是派生轮廓，不能精确保留孔洞；继续由无损RLE保存/COCO RLE导出保障形状。不得因增加手绘工具而宣称YOLO无损。

## 7. 快捷键与双语布局

保留现有B（SAM提示框）、E（负点）、R（检测框）、V/Shift+V、N、X、Ctrl/Cmd+Z等，避免改变肌肉记忆。新增：

| 操作 | 快捷键 | 焦点/冲突规则 |
| --- | --- | --- |
| Brush / 画笔 | W | 未输入文字、无模态窗口时 |
| Eraser / 橡皮擦 | J | 不复用E |
| Polygon / 多边形 | P | 不隐式切换添加/减去模式 |
| 减小/增大笔刷 | [ / ] | 仅画笔/橡皮擦；按约10%取整变化，至少1px |
| 完成多边形 | Enter | 优先于SAM细化 |
| 删除末顶点 | Backspace | 有未闭合路径时不删除实例 |
| 取消手势/路径 | Esc | 优先于取消选择或关闭右栏 |

绘制草稿期间屏蔽X/Delete/审核快捷键，画笔/橡皮擦期间同时屏蔽Backspace，避免误删底层实例或批准未完成内容；Ctrl/Cmd+Z优先取消当前未提交笔画，多边形优先撤回末点。输入框、中文输入法组合态、弹窗/菜单优先获得键盘事件。手工工具没有活动路径时Enter不触发SAM，需明确切回提示工具或点Refine mask。

短标签对照：Brush/画笔、Eraser/橡皮擦、Polygon/多边形、Size/大小、Add/添加、Subtract/减去、Finish/完成、Cancel/取消、New object/新物体。英文不截成不可辨认缩写；尺寸数字用等宽数字与固定px单位；多边形模式不能只用颜色或正负图标，以免与SAM正负点混淆。完整tooltip与aria-label通过i18n响应语言切换，快捷键查询增加情境说明。

## 8. 验收与展示

布局验收覆盖英文/简体中文、1440×900、1280×720和窄窗口：手工/选择/SAM切换时画布可用尺寸不变；右侧视图控件不跳位，新增工具可滚动访问，长类别名称不影响参数；浏览器200%缩放也能访问完成/取消及数值输入。

行为覆盖：无模型从零创建；修补SAM/RLE/polygon-only；单像素、孔洞、断连、重叠实例、边缘裁剪、快速笔画；多边形退化与自交；无变化操作；擦空、撤销重做、保存失败；显隐/锁定；切图A→B→A、切实例/工具/项目、pointercancel；未保存mask立即显示与命中；旧SAM/候选/批次结果拒绝覆盖人工编辑；保护标记重启保持及显式预览替换；所有手工操作不加载模型，mask-only不产生box。

交付实现代码和临时数据集上的实际浏览器预览，截图放忽略目录docs/design-previews。版本与发布记录见[0.5.0](../releases/0.5.0.md)。自动化覆盖像素codec、几何操作、手势取消、撤销、缓存淘汰及人工保护路径；真实模型的替换质量、CUDA/MPS及超大图性能仍需目标环境验证。


### 本轮已执行的验证（2026-11-01）

- Ruff format/check、249项Python测试、224项前端测试及TypeScript/Vite构建通过。构建仍有既有的大chunk提示。
- 20组随机形状与pycocotools交叉验证，前端编码逐字节一致并可双向解码；另有孔洞、断连和畸形编码固定回归用例。
- 本机Node运行3840×2160二值缓冲：120段笔画约3.5ms，RLE编码约17.2ms、解码约1.0ms；单二值缓冲约7.9MiB。这是像素运算测量，不等于浏览器完整渲染、60步历史内存或GPU性能承诺。
- 临时COCO图片项目的实际浏览器操作覆盖画笔、多边形添加/减去、橡皮擦孔洞、快捷键、整步撤销、自动保存和重载；确认没有自动生成box。检查英文/中文1280×720及1440×900布局，并检查720×450窄窗口可滚动参数区。尚未单独完成浏览器200%缩放及超大图长时间绘制验证。
- 独立审核提出的快捷键映射、历史命中缓存泄漏及笔画中Backspace误删均已修复并复核；浏览器检查另修复工具按钮焦点导致Enter不能完成多边形的问题。真实SAM替换质量及CUDA/MPS本轮未重新测试。
