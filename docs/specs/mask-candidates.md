# 交互式候选掩码（0.2.0）

2026-10-22，依据用户确认的设计实施，协议测试与合成数据交互验证；真实权重/硬件验证边界见末节。默认点/框分割保持单掩码；多候选为同一实例的替代解释，不是多个实例。批量、CLI、自动切图、当前图批量补 mask 始终单掩码，后端显式传 `multimask_output=False`。SAM 3 文本多实例流程独立。

## 交互

- 右侧实例列表的展开操作中，Refine mask 旁提供 Generate candidates。仅对有正负点/框提示、可见、未锁定且未排除的实例和已声明支持的模型开放。没有提示时给出提示，不退化为整图自动分割。
- 画布下方、图片缩略图上方出现临时候选条；显示加载、最多三个候选的轮廓缩略预览和预测质量分数，按有限质量分数降序（无分数最后，稳定排序），默认第一个。分数不是准确率/概率；无分数只显示编号。一次只在主画布预览一个候选并替代该实例原 mask 的显示，其他实例保持原样。候选条改变画布尺寸时，原适应画布状态自动重新适应，手动缩放/平移状态保持比例并维持视图中心。
- 点击候选切换预览；候选条获得焦点时左右键切换、Enter应用、Esc取消，拦截冒泡；未聚焦时左右键继续切图。画布有候选时 Enter 应用、Esc取消，输入框与其他弹层仍优先处理。
- Apply才保存：同一个实例UUID、类别、显式box、提示均保留，只替换mask/RLE/polygons/source并将Segmentation设为pending。不会自动生成box，不改变Detection审核，不自动Approved。取消恢复原标注；候选预览不进入撤销或自动保存，应用后可撤销；撤销仅改变mask时不使Detection审核失效。
- 保留单一候选会话及请求代次。新增/修改提示后清除旧预览，保存提示后防抖重新生成；其他实例编辑、类别/锁定/隐藏/审核/备注变化、模型选择/设备参数切换、选中实例变化、项目变化均使旧候选失效。失败保留原mask，允许重试/取消。切图丢弃候选并短暂提示，不阻止原标注自动保存；晚返回结果不应用到新图。

交互式单掩码自动更新复用只读预览接口，显式传multimask_output=False，通过adapter.predict（其底层False）生成最多一个结果；默认多候选调用仍为True。自动预览不打开候选条；响应通过当前项目/图片/实例、参数、revision和编辑代次校验后才合入本地并按普通标注保存。两种预览共享单一在途请求限制，候选模式内不同时生成单掩码。

## 后端与数据边界

- `POST /images/{id}/mask-candidates` 通过交互单线程执行器在只读标注快照上推理，要求 instance_id、非文本、合法点/框。响应包含项目/图片/实例ID、revision、图片mtime/size的精确字符串指纹、model、候选RLE/polygons/PNG预览/可空quality。最多返回三个，不写标签、审核、统计或候选缓存。
- `POST /images/{id}/mask-candidates/apply` 使用revision和图片指纹复核当前数据；修改或外部标签冲突返回错误，不覆盖人工编辑。只接收选中的RLE，服务端校验尺寸/非空并重新计算polygon，再经原Project.save事务提交。无推理/服务器会话缓存，无候选累积；模型质量分数只用于候选选择，不混用检测confidence。
- 预览PNG为透明类别颜色覆盖层，实际RLE是保存真值；主画布不得把近似polygon当作有孔洞mask的真值。内存只保留当前组至多三个候选及当前组的图片缓存，切换/取消后释放。原图与已有mask仍沿用原服务接口。
- 当前Ultralytics SAM、SAM2、MobileSAM、SAM3视觉提示适配器声明候选能力；实际依赖版本需支持对应predictor。模型列表声明候选能力；不支持的模型明确禁用，不能把文本多对象结果冒充候选。单掩码路径显式False，多候选路径显式True；不可通过批任务请求打开候选模式。

## 验证

验证适配器参数/质量对应与排序、空和异常输出、mask-only保持无框、只读预览、仅选中候选写入、revision/图片/外部标签冲突、批次单掩码、取消/切图/编辑/晚响应保护、提示防抖重算、候选局部快捷键、双语与窄屏排版。真实权重及CUDA/MPS的候选差异和性能需在目标环境实测；合成适配器仅验证协议。

接口参考：[Ultralytics SAM Predictor](https://docs.ultralytics.com/reference/models/sam/predict/)。

0.2.0真实验收见[验证记录](../validation/real-models-2026-10-22.md)：SAM 2.1 Tiny在CPU/MPS通过实际提示组合，MPS 16图128次调用覆盖正点、正负点、框及框加正负点的单/多掩码。输入点必须为`[1,N,2]`、标签为`[1,N]`，不把N个点解释为N个对象。真实模型可返回少于三个有效候选，也可能全部为空；空输出保持原标注并提示。原图尺寸、候选只读、过期Apply拒绝、mask-only与中文页面交互均已复核；其他模型及CUDA仍未实测。
