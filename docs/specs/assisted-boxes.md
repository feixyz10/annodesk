# AnnoDesk：自动框、严格类别校验与模型/任务窗口

状态：随0.3.0更新至2026-10-26；自动框自0.2.0起已实现并通过自动化与合成数据交互验证，真实模型/加速器验证边界见§7。与主 spec 冲突时，本增补中涉及自动框功能的条款优先。保持浅色界面（支持英文/简体中文）、本地模型、tyro与单协调者写入；不引入通用插件框架或分布式服务。

## 1. 常驻统计与两类窗口

审核统计栏始终位于工具栏下，按 Detection/Segmentation 显示全项目 Approved/总数与四类排他计数，不随Tasks关闭或任务结束隐藏。四类为Not reviewed、Approved、Needs review和Excluded，不合并为Reviewed。自动结果不算人工审核。

模型设置改为居中模态窗口（约900px，最大90vw/80vh）：Detection/Segmentation、模型选择与Available/Loaded状态、显式Load、兼容检查、检测阈值/conf、NMS IoU、imgsz、max_det、模型类别筛选、设备设置及允许新增类别。重新加载模型配置时清除旧的兼容检查；若所选模型被删除，切换到当前任务的有效默认模型。仍存在的模型保留未应用参数草稿。Apply才保存参数；Cancel不应用未确认设置。加载是运行时动作，可独立于Apply；SAM加载失败清空未完成predictor及相关缓存，切回原模型或重试必须重新初始化，窗口同步实际加载状态；提示中不包含后端路径，主动展开的诊断与日志可包含。

工作台仅保留当前任务模型的紧凑设置入口、Detect current/Segment current及自动切图处理开关；框来自mask的操作放在当前图片/选中实例区域。Pan与缩放/Fit保持同组。创建工具按标注结果/SAM提示分组，检测框类别色实线，提示框琥珀色虚线。选择范围默认结果，提示层不拦截检测框或mask；显式切到提示范围才编辑提示。实例属性按两组提供几何直接选择，重叠时可明确选中任何目标。选择工具区分显式框、无损mask、提示与整实例；X/Delete仅删除当前选择目标，删除框保留mask，删除mask保留框。选中对象常用操作放在右侧属性面板；上部实例列表常驻新物体并在选中行内展开全部实例操作，下部常驻图片属性，不再使用Object/Image页签，画布上方仅保留48px单行工具；选择、展开或收起实例不推移画布；清空本图提示仅清理未锁定实例的点/提示框，保留mask与检测框并可整次撤销，右侧上下区域可调比例并独立滚动；窄窗口提供图片详情入口，不隐藏实例操作的唯一入口。

Tasks使用居中模态任务窗（约900px，最大92vw/85vh），关闭后继续标注。启动自动展开，关闭仅收起，顶部继续显示轻量进度；完成不抢焦点。展示配置快照、时间、进度、实例计数、worker、错误及历史任务。窗口内键盘操作不能误触画布快捷键。Logs/Classes/Tags统一为居中窗口。Classes/Tags编辑使用草稿，失败不改变字典或实例显示名称；只有后端确认成功才更新项目元数据。

## 2. 检测模型与类别来源

0.2.2预设检测为随包的YOLO11n COCO 80类权重；它仍须通过严格项目类别检查，不因默认模型而自动新增或重映射类别。标准安装包含Ultralytics/PyTorch，检测与分割地位对称；不提供inference extra。权重存在与推理依赖安装状态独立，启动和页面分别提醒；其他配置语义保持不变。

models.json新格式按segmentation/detection对称分组，各组有default_model和models；模型条目保留backend及可选classes_file，task由分组确定。旧顶层扁平格式（default_model/default_detection_model/models）继续兼容，但不能混用两种结构；旧SAM条目自动属于segmentation。仅有det配置也合法，不得把det模型用于SAM提示。

source依然精确到模型目录，目录内必须有唯一兼容.pt，禁止下载。classes_file支持JSON/YAML，使用names数组或ID到名称的字典，非空、名称非空且唯一、ID为连续0..nc-1；相对models.json解析，不尝试HF_MODELS。

优先读取标准Ultralytics检测权重的可靠names。缺少/仅占位名称时要求classes_file并验证模型nc。若两处都有可靠定义，完整(ID,name)表必须相同，否则直接报错；不得通过sidecar偷偷改写真实模型类别。仅含state_dict、无法初始化检测模型的文件，不因有类别文件就承诺兼容。

严格项目兼容：模型和项目的(ID,name)集合完全相同，或任一为另一的子集。相同ID不同名、同名不同ID、互不包含都报错，不做别名/大小写转换/重映射。类别文件变化、模型变化、项目类别重排/改名后重新检查。项目内部仍以UUID关联实例，数字ID用于对外序列化。

## 3. 新类别与提交一致性

Allow new classes from this model默认关闭，按项目/模型保存，任务启动后冻结。关闭时丢弃超出项目的类别并统计；开启时只有通过conf/NMS/类别筛选/几何校验且最终保存成功的检测结果才引入类别。已有YOLO框导入在首次物化前检查实际边界和正面积，沿用保存时的微小舍入容差；真实越界报标签文件及行号，不作为后续检测、分割或导出的有效输入。保持模型数字ID，新建项目UUID和颜色，不按max+1重新编号。

类别元数据、data.yaml、内部实例和YOLO投影在同一恢复日志事务中提交；revision/外部指纹冲突不得留下幽灵类别。失败图片不新增类别。所有worker只返回候选，主协调者验证当前类别体系并提交。已删除类别的保留记录不得被自动恢复。兼容空项目但toggle关闭时无可接收类别，开始前明确报错。

允许工作类别ID空洞；重新打开不能补出未识别类别。训练导出生成连续ID副本和class-id-map.json，不回写工作ID；不能承诺稀疏data.yaml可直接用于Ultralytics训练。所有新增类别在Class palette可用，可手动调色。

## 4. 操作语义

Detect current及Auto-detect on navigation（默认关）：由检测模型产生可编辑的框、类别与原始置信度/模型来源。默认fill_empty，只处理尚无实例的图片；append显式追加，按相同目标类别、IoU>=0.7去重（mask实例可用其临时包围框检查）。不替换人工实例，不修改已有mask，不自动确认空背景。当前图检测、SAM和几何请求在入队前冻结标注/提示及图片、标签指纹，执行和提交前校验；排队期间被人工保存的图片拒绝旧请求，不以执行开始时的新revision替换原请求上下文。没有结果是成功处理0个框，审核状态不变。发生新增时Detection回到pending。

Boxes from masks：选中实例、当前图、批量都可用。纯几何计算，不加载Torch/SAM或GPU；RLE优先，polygon后备；RLE按像素边界[xmin,ymin,xmax+1,ymax+1]，polygon按连续坐标范围；裁剪到图片范围，空/退化几何跳过，不连通部分仍为同一实例的一个包围框。保留实例UUID/类别/mask；默认仅缺框，Recalculate boxes显式允许替换未锁定框。框后续可人工调整，不随mask编辑自动重算。手动拖绘、移动及缩放在切图、导航、项目、工具或标注上下文变化时取消，旧手势不能落入新图片。只增加/改框不修改Segmentation状态；Detection有变化时回到pending。普通SAM仍不自动保存框。检测与SAM（含候选和批处理）接收与预览相同的Pillow首帧RGB栅格转换的BGR ndarray，不独立从文件再次解码方向；尺寸与坐标约定遵循主spec，导出必要时规范化图片副本以保留坐标对应关系。手动调整已有框与该几何操作不同：移动、缩放和数值改框均保留关联mask，并将Segmentation置为uncertain；锁定实例禁止手动改框。

## 5. 范围、审核筛选与预检

批任务类型：detection、segmentation、boxes_from_masks，导出保持独立。默认只选pending，可显式选择uncertain/ok；Excluded始终跳过。det及mask转box按Detection审核筛选，SAM按Segmentation筛选。锁定按实例保护；状态筛选不授权覆盖人工标注。

范围支持全项目或当前图片搜索过滤结果。预览只读、不物化内部标注：固定优先级excluded→review_state→无可处理内容→eligible，损坏输入独立计失败；给出input_total、各跳过数、需处理数及类别兼容摘要。Start不依赖用户先点击Preview scope：先保存当前标注，再自动预检同一份冻结参数；检测另做类别兼容检查，无可处理图片时展示范围结果、不创建任务。等待保存/预检时关闭窗口、改变配置或切换项目会使启动操作失效。开始重新验证并冻结范围、参数、类别表、模型/类别文件/设备计划。单独的scope预览不冒充已完成模型加载/类别验证。

Resume延续原任务范围/配置，不受当前筛选和参数影响；checkpoint或类别表变化不能静默恢复。新批次重新计算。检测任务运行期间禁止手动新增、改名和重排类别（颜色可调整）；恢复校验项目类别快照，允许本任务此前成功保存所引入的类别。排队期间变为不符合审核筛选的图片拒绝处理并计入失败，保留人工决定。F/T图片进度与boxes_added/dropped等实例计数分开；成功必须在协调者保存后计数。取消、保存冲突、worker崩溃、项目写锁沿用0.2约定。批处理/导出活动期（含取消后等待在途worker）拒绝回收站清理及恢复，任务启动与回收站操作互斥；批次报告冻结图片路径，图片被外部移除只计该图片失败，不丢失错误明细或中断其余图片。

## 6. API与CLI

serve（含--api-only）拥有数据集读写、模型与推理；ui只是独立网页主机，浏览器直接连接API。普通服务器使用serve即可由本机浏览器远程标注；本机数据集上传至远端纯推理服务的能力尚未实现。help与用户指南须明确运行电脑及浏览器访问地址。

0.2.2补齐逐参数说明，包括None/auto默认行为、类别筛选及追加策略；只读models list不再暴露无效日志选项。

0.2.1整理CLI帮助用途和顺序，移除仅开发使用的build-ui；此处三类用户批处理命令及参数保持不变。

保留现有segment接口和SegmentRequest兼容，增加operation与检测/类别/审核/范围参数；当前图提供detect、boxes-from-masks端点，/jobs/preview只预览范围，/jobs支持三类任务。/models/check进行独立CPU探测与兼容检查；/models/load在交互执行器加载指定设备模型；/model-settings保存项目级模型参数，不写标注。

CLI增加detect、boxes-from-masks；segment增加审核筛选。三类CLI不需要UI/HTTP，日志、退出码、报告、恢复与设备语义一致；几何任务不接受GPU/多worker配置。检测报告包含类别快照、参数、逐图结果、新增框与丢弃数量；内部存储原始置信度，不扩展YOLO标准txt列。

纯几何CLI不创建ModelRegistry，也不读取models.json或ANNODESK_MODELS_CONFIG；模型配置缺失或损坏不应阻止已有mask转框。

## 7. 验证与边界

验证旧配置兼容、det-only配置、sidecar路径/冲突/nc、严格包含关系、空项目与toggle、稀疏ID重开/导出、同事务冲突保护、首次物化与人工保存串行且初始化不覆盖现有记录、只读mask查询、类别变化拒绝在途保存、mask单像素/孔洞/断连/polygon、锁定与审核失效、只读预检、范围/恢复、spawn检测候选单写、异步返回保留编辑。前端验证窗口可收起且不停止任务、设置Apply/Cancel、状态区分与常驻统计。使用临时数据/假适配器验证协议，0.2.0已完成SAM 2.1 Tiny与YOLO11n的CPU/MPS及双worker真实验证，见[验证记录](../validation/real-models-2026-10-22.md)；CUDA及其他模型仍未实测。


Mask 转检测框支持每侧外扩：pixels 为每侧像素数；ratio 为当前 mask 紧包围框宽/高的比例（UI 用百分数，CLI/API 用小数，0.1=10%）。min 勾选时覆盖模式，横/纵方向分别取像素与比例外扩量的较小值；最终裁剪到图片边界。默认 0，不改变原有紧框。右侧实例属性和批任务提供相同设置，本次会话共用；任务启动后冻结配置。CLI 使用 --box-padding-mode pixels|ratio、--box-padding-pixels、--box-padding-ratio、--box-padding-min。仅创建缺框/显式重算、锁定保护及审核语义不变。撤销/重做放在独立“历史”工具组；“编辑 SAM 提示”提供直接进入提示选择范围的入口。框缩放允许独立调整宽高，不默认保持比例。


交互补充：普通选择与SAM提示选择保持分开。V与普通选择按钮共用入口，退出提示选择范围；在输入框中输入v不触发工具快捷键。同一实例名称再次点击切换展开/收起并保留选择；几何图标始终选中对应目标并展开。文字提示工具在画布内显示绝对定位输入浮层，自动聚焦输入，关闭或Esc返回普通选择，不改变画布尺寸。工具光标区分普通选择、箭头加各自工具标记和手形平移（拖动时闭手），Space临时平移松开/窗口失焦后复原；缩放控点仍显示方向光标。属性开关固定在画布工具栏最右侧、紧邻右栏，视图控制保持同组，左侧模型/推理控件空间不足时在自身区域横向滚动。

实例搜索框上方提供“清空本图标注…”：确认窗口显示实例数量，删除目标包含其框/mask/全部提示；默认保留锁定实例，可明确勾选包含锁定实例。操作一次撤销，保留tags、备注、项目类别与排除状态，Detection/Segmentation审核回到pending，清除两任务的explicit_empty，不自动认定为已确认负样本。清理替换当前编辑上下文、使未完成画框及在途推理/候选失效；确认窗口绑定图片和项目会话，切图/切项目/导航时关闭，不得误清其他图片。


统计和默认分割交互增补见主spec §10.3：常驻框/mask总数与“更多统计”窗口；按类别表格/水平柱状图切换，默认不含排除图片，可切换范围，审核统计始终覆盖全部图片。内部JSON优先、YOLO导入未物化时只读计数，不创建标注、不读像素。Auto-segment默认开启，仅对未排除、pending、可见未锁定且缺mask的检测框自动处理；模型/依赖不可用则不派发自动请求。检测默认开关保持关闭。


导出交互增补：Export打开统计确认窗口，选择任务、YOLO/COCO、include_pending及后端新目标目录。默认仅ok，uncertain/excluded始终跳过；pending须明确加入，有效实例或explicit_empty规则不变。自动保存后调用只读/export/preview，不物化导入记录，显示total、四种审核状态、eligible、各类skip及invalid明细；修改配置/目标后重新计算，确认前不启动任务。零eligible或invalid禁止确认。确认传入输出路径及源signature，执行前持项目锁重验，过期确认失败。源signature包含任务/格式/审核选项、类别、图片路径/尺寸/mtime、内部标注及外部投影指纹，不含输出路径。默认私有导出目录，指定目录支持绝对/相对项目根路径，禁止工作数据集内其他目录与覆盖已有目录。导出失败/取消只删除本次新建输出；复用已有输出前仍检查取消，取消时保留已有数据集。成功记录实际exported/skipped、文件SHA256清单及项目导出历史；源及选项一致且输出清单/校验和完整才提示已导出并复用，指定不同新目录可重新复制。历史旧版无清单输出不自动复用。导出为目录，无浏览器下载。三项图片级操作移至实例搜索框上方一行，使用短标签及完整tooltip，几何缺失/锁定状态决定禁用；Auto-detect默认关闭。

导出统计不显示Reviewed汇总层；图片总数下为同级的Not reviewed、Approved、Needs review和Excluded。预计导出数单独展示，由任务、审核筛选及有效标注共同决定。无效输入未能读取审核状态时计入总数及无效明细，不虚构审核分类。确认按钮固定在窗口底部，统计内容独立滚动。

导出跳过明细在存在跳过图片时默认展开，只显示非零原因计数及最多100张图片的相对路径/原因，超出显示已展示/总跳过数。无当前任务有效实例且explicit_empty未确认的图片归为no_annotations，即使包含未审核标注也不能作为负样本导出；用户需补标或明确确认无目标。


管理界面统一为居中临时模态窗口：Classes、Tags、Models、Tasks、Logs、Statistics、Shortcuts，以及批量、导出和确认对话框；内容内部滚动，关闭后继续标注。画布、左右常驻面板及画布内文字提示浮层保留原布局。窗口打开期间工作台快捷键不得误改图或标注；关闭Tasks/Logs不停止后台任务或日志写盘，后台更新不抢焦点重新打开窗口。可停靠常驻侧栏为未来设计，本轮未实现。

图片审核：无当前任务有效几何时仍允许pending/uncertain及excluded；新设为ok必须有该任务标注，或先明确设置explicit_empty。前端按钮与1快捷键共用检查，服务端拒绝新增空批准及移除批准结果/无目标确认后仍保留ok的保存；对旧版已存在的无效ok记录不做隐式重标。取消空图的无目标确认时，该任务ok退回pending。导出四类状态下各自缩进显示no_valid_annotations数量：无该任务几何且未确认无目标；这是所属状态的子集，不与状态数量相加，也不计入有效负样本。总量和跳过明细规则不变。

空图尝试通过审核时，使用居中提示窗口替代顶部错误条，说明补标/确认无目标要求；“打开图片属性”只展开并定位确认项，不自动勾选或批准。“继续标注”关闭提示。后台轮询、统计及日志连接错误仍采用现有非打断式反馈；本轮未将所有错误统一为弹窗。


非阻断全局错误使用顶部居中固定悬浮通知条，不进入布局，不推移画布、图片列表或统计。保留关闭及未保存时的重试保存，长消息可展开详情，不自动关闭，不强制转移焦点；后台轮询不反复弹出对话框。空图批准等明确被阻止的操作使用前述居中提示窗。

Export summary与Skipped images均按四种审核状态分组，状态下缩进列出“无有效标注且未确认无目标”的子集。主统计子集包含该状态所有图片；Skipped子集只包含实际跳过图片，不与父级相加。无效输入无法读取状态时，另列“审核状态无法读取”，不伪造四类归属。API增加skipped_by_state及skipped_no_valid_annotations；各状态跳过数含unknown之和等于total-eligible，底层skip原因优先级不改变子集归属。

“Confirm no objects for this task / 确认此图片在当前任务下没有对象”固定在图片审核按钮正下方、tags/备注之前，使用浅色强调区，始终占据固定位置。确认与批准独立，不自动设为Approved；提示窗继续定位该项。

Objects/实例区域始终展开，不提供整区折叠入口；列表、搜索、图片级操作及区域分隔条保持可见。各标注目标的操作详情默认收起，即使挂载时已有选中对象也不自动展开；点击名称或几何图标按既有规则展开，再次点击名称可收起。

统计子项界面短标签统一为“No valid annotations / 无有效标注”；悬停说明仍为无该任务有效标注且未明确确认空背景，统计规则不变。

导出文件级明细（图片路径、跳过原因及无效输入错误）置于独立滚动区域，高度上限min(240px,30vh)，支持键盘滚动，滚动不串到父窗口；审核状态统计和已展示/总跳过数量保留在区域之外。仍至多列出100张跳过图片，不用长文件清单撑开导出窗口。

跳过图片清单每行只显示“相对路径 — 简短原因”；no_annotations使用“No valid annotations / 无有效标注”，不再重复追加确认空背景的完整解释。
