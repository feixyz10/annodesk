# AnnoDesk 0.3.0

2026-10-26。本地发布，提供 wheel、源码包及 SHA256 清单；暂不上传 PyPI。

## 交互式标注

- 正负点和 SAM 提示框在短暂防抖后自动更新选中实例的 mask；普通自动处理与批量处理始终使用单掩码，候选需显式预览并应用。
- 检测框、mask、SAM 提示分开选择和删除，选中 mask 显示边缘。检测框支持移动及独立宽高缩放；`N` 开始下一个物体，`V` 返回普通选择。
- 清空单实例提示、清空本图提示、清空本图标注和删除整实例都有明确入口及撤销支持；清空标注先确认，默认保留锁定实例。
- mask 转框支持每侧像素/比例外扩，以及取两者较小值；裁剪到图片边界，纯几何处理无需模型。
- 文字提示使用宽幅多行浮层，工具使用带标记的箭头光标；Auto-segment 默认开启，Auto-detect 默认关闭。

## 工作台与统计

- 画布上方压缩为单行工具栏。右侧实例列表固定几何/显隐/锁定列，实例详情默认收起，点击展开后可更换类别、细化 mask 和处理几何；下方为独立图片属性，分隔比例可调整。
- 类别、标签、模型、任务、日志、统计和快捷键统一为居中临时窗口。任务关闭后继续运行，完成不抢焦点。
- 常驻审核统计使用 Approved/总数及四个互斥状态，新增框、mask 总数和按类别的表格/柱状图。
- 空图片通过审核前须补标或明确确认无目标；确认入口位于审核按钮下方。一般错误用固定悬浮通知显示，不推移工作区。

## 批处理与导出

- Batch 的 Start 自动保存及预检，Preview scope 为可选操作；同一会话元数据刷新不再造成任务窗口闪烁、画布重新加载或实例搜索丢失。
- Export 先展示审核/有效标注/跳过统计，确认后再生成完整数据集副本。支持指定后端新目录、源数据签名校验、文件清单与校验和，以及复用未变更的完整导出。
- 四种状态下缩进显示“无有效标注”子集；文件级跳过详情独立滚动，最多展示100张。未确认无目标的空标签不会作为负样本导出。
- 取消与失败仅清理本次未完成输出，复用旧导出也检查取消并保留已有目录。

## 配置与升级

默认分割模型改为 `facebook/sam2.1-hiera-small`，检测仍为随包 YOLO11n；SAM 权重需自行放在本地目录，绝不自动下载。自定义 `models.json` 继续优先生效，Tiny 等其他配置仍可选择。

安装前备份整个项目。内部 JSON/RLE 仍为权威数据，`labels` / `labels_seg` 为工作投影，导出副本使用连续类别 ID 并附 `class-id-map.json`。未新增远程纯推理节点、本地浏览器数据上传、认证或数据集下载功能。升级后建议强制刷新浏览器以加载新前端资源。

## 验证与边界

两轮独立 subagent review 已完成：接受并修复同会话刷新重置画布/实例状态、导出复用忽略取消的问题；补充回归测试，并修订文档和默认模型测试。

发布检查包含 Ruff format/check、237 项 Python 测试、170 项前端测试、TypeScript/Vite 构建及仓库外 wheel 的 CLI 帮助、用户指南、预设模型、API 和静态资源冒烟。前端测试包含英文/简体中文渲染及翻译覆盖。此前真实 SAM 2.1 Tiny / YOLO11n、16 张 COCO 图片、CPU/MPS 验证见[历史报告](../validation/real-models-2026-10-22.md)；本次未重新进行真实模型质量评测，不新增 CUDA、多 GPU、Small 模型或其他模型家族的硬件验证声明。
