# AnnoDesk 0.5.0

2026-11-01。新增无需模型的手工掩膜创建与修补。本次不上传PyPI。

## 手工编辑

- 左侧掩膜组提供画笔（W）、橡皮擦（J）、多边形（P），支持添加、减去、孔洞及断连区域。
- 顶部复用既有工具栏显示笔刷尺寸或多边形操作，不增加画布上方行数；中英文同步。
- N开始新物体；Enter完成多边形、Backspace撤点、Esc取消。每笔或每片支持撤销和自动保存。
- 保留实例类别、检测框和提示；不会自动创建检测框。隐藏、锁定或已排除的目标禁止编辑；切图等上下文变化取消未完成手势。

## 人工结果保护

- 新增持久化mask_manually_edited字段，旧数据默认false。自动和批量分割跳过人工修改，包括有意擦空的结果。
- 显式SAM细化先预览，应用替换后才写入；保护标记保留。批量范围统计显示手工保护跳过数。
- RLE保留完整像素，YOLO多边形投影仍可能丢失孔洞。

## 验证与升级

Ruff检查、249项Python测试、224项前端测试及前端构建通过。浏览器实测手绘、挖孔、多边形增减、撤销、保存重载和双语布局；修复快捷键映射、历史命中缓存、Backspace误删及Enter焦点问题。

20组随机形状与pycocotools双向验证。4K像素运算测试不代表完整浏览器渲染或长期历史内存性能；本轮未重新验证真实SAM替换质量、CUDA/MPS及浏览器200%缩放。构建保留已有大chunk提示。

升级前备份整个项目（包括.annodesk）；新保护字段随内部标注保存，旧版本不提供该保护语义，不建议用旧版本继续编辑新数据。
