# AnnoDesk 0.4.0

2026-10-29。本地发布包：wheel、源码包和 SHA256 清单。本次不上传 PyPI。

## 画布选择

- 移动光标预选框、mask或提示，画布轮廓与右侧实例行同步提示；点击才正式选择，悬停不展开详情或修改标注。
- 正式选中框或mask时，轻度强调同实例的另一种几何；删除与变形仍只作用于明确选中的目标。
- `V` 选择标注结果，`Shift+V` 选择SAM提示；Space临时平移期间暂停预选。

## 分层显隐

- Layers提供当前项目全部图片的框、mask、SAM提示开关，以及检测/分割/全部图层预设；不切换审核任务。
- 实例行的三个几何图标直接控制各自显示，列头对应图标批量控制整张图，不受搜索筛选限制。缺失几何保持占位；精确选择移至更多/右键菜单，也可在画布完成。
- 实例眼睛与列头眼睛在任意几何可见时点亮，全部隐藏时变暗。点击亮眼睛隐藏该范围；点击暗眼睛显示该范围。整图隐藏后，仍可独立显示一个实例或一个几何，眼睛立即联动。项目级开关保持优先。
- 列头以浅灰蓝底色和细底线标识整图操作；图标与实例行同尺寸、同显隐样式，不使用额外的“−”标记。
- 显隐仅保存为浏览器偏好，按项目根目录/ID及图片隔离，存储受限时会话内降级。它不修改标注、审核、导出、统计或模型处理范围；旧记录的hidden字段也不再阻止候选生成。
- 隐藏几何不参与画布命中或编辑。隐藏选中几何清除编辑目标但保留实例上下文，避免Delete意外删除整个实例；显隐变化取消未结束的拖绘。隐藏图层的绘制有明确恢复入口。

## 升级

```sh
python -m pip install --upgrade ./annodesk-0.4.0-py3-none-any.whl
```

安装后重启后端、刷新浏览器。标注与模型配置格式保持不变，不自动下载模型。实例行几何图标的单击语义从选择改为显隐，精确选择请使用画布或更多菜单。
