# AnnoDesk 0.2.2

2026-10-26。本地发布，提供 wheel、源码包及 SHA256 清单；尚未上传 PyPI。

## 更新

- 模型配置按 `segmentation` / `detection` 对称分组，各自拥有 `default_model` 和 `models`；旧扁平配置继续兼容，不允许混写。
- 默认分割为 `facebook/sam2.1-hiera-tiny`；SAM 预设使用完整 repo ID。默认检测为随包提供的 YOLO11n COCO 权重，SAM 权重仍需本地准备。
- 启动及中英文页面分别提示找不到模型、缺少推理依赖；不自动下载权重或安装依赖，手工标注仍可使用。
- 模型配置可在未打开项目时查看和重新加载；实际模型加载与保存项目设置需先打开项目。
- 删除独立 `api` 命令，统一使用 `serve --api-only`；与 `--open` 同用时明确报错。
- CLI 各参数补充用途与省略/None/auto行为。移除 `models list` 原先不生效的日志参数。
- `serve`、`serve --api-only`、`ui` 的 help 和用户指南明确命令运行电脑、浏览器地址及数据路径归属。
- AnnoDesk 原创源码声明为 MIT；第三方模型及依赖保留各自许可证。

## 部署边界

通常在GPU服务器运行 `annodesk serve --host 0.0.0.0`，本机浏览器访问 `http://服务器IP:8765` 即可。`serve --api-only` 省略网页，`ui` 只提供网页及后端地址，用于独立托管和开发。数据集、模型、读写和推理始终由API电脑管理。

“本地项目读写、逐图上传到服务器纯推理、结果返回本机保存”尚未实现。已有部署分离不提供此能力。

## 兼容与验证范围

自定义模型ID和旧JSON仍可使用；分组默认ID须属于对应组，模型ID全局唯一。目录相对JSON解析并回退HF_MODELS的规则保持不变。项目内部标注和YOLO格式不变，升级前备份整个项目。

验证包括配置兼容/拒绝歧义、真实spawn worker处理分组配置、CLI帮助、双语提示、wheel内置权重哈希与路径及仓库外安装冒烟。内置YOLO11n经真实CPU适配器加载验证80类；没有新增CUDA/多GPU验证或分割质量评测。历史真实模型范围见[验证记录](../validation/real-models-2026-10-22.md)。

发布前自审修订部署角色/地址说明、未打开项目时的模型操作提示及本地包安装步骤。210项Python、89项前端测试、Ruff、前端构建、锁文件与版本一致性检查通过；安装包另在仓库外验证文档、CLI、默认模型、API和静态资源。
