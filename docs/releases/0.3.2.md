# AnnoDesk 0.3.2

2026-10-28。提供 wheel、源码包及 SHA256 清单。

## 导入与自动分割

- 同时导入 `labels` 与 `labels_seg` 时，按类别及几何位置进行保守关联，不依赖标签行序：双方各只有一个重叠候选且包围框 IoU ≥ 0.9 才合并为同一实例，保留原框和完整多边形。
- 无法唯一关联时保留原有实例。与未关联同类掩膜重叠的框，自动切图、当前图补全以及批量/CLI 分割均跳过；其他缺掩膜框仍可处理。人工核对后可显式选择实例细化。
- 首次导入统计使用相同关联规则。已有内部记录不自动合并，也不删除此前已经产生的重复掩膜，保留实例 ID 和人工修改。
- **Auto-segment 默认关闭**，可在工具栏开启，当前页面会话内有效。该开关控制切图时补掩膜；正负点和 SAM 提示框仍会触发交互式分割。Auto-detect 继续默认关闭。

## 实例操作与掩膜转框

- 实例名称与几何图标单击只选择；双击名称或点击展开箭头才展开/收起详情。选择另一实例时收起旧详情，不自动展开新详情。画布上双击实例仍用于修改类别。
- 单实例创建/重算、整张图补框以及右键菜单统一打开外扩设置窗口，直接展示像素、比例和 min 选项，确认后执行。整张图补框保留已有检测框。
- 确认时冻结目标实例、处理范围和外扩参数。等待自动保存时切换或取消选择不会把单实例重算扩大为整张图；若期间出现新标注编辑，则提示重新执行。
- 同步更新中英文界面、快捷键说明、用户指南和设计规范。

## 升级

```sh
python -m pip install --upgrade "annodesk==0.3.2"
```

升级前备份项目，升级后重启后端并刷新页面。模型配置、类别和标注文件格式保持不变；没有权重下载或已有项目记录的自动迁移。新导入的关联规则不能替代对歧义对象的人工检查。
